**Autarch は技術的評価だけでは決定できず、利用者の優先順位が必要です。**

決め手は一点だけです。**ノートのデータを、CLI の外側(テキストエディタ、`grep`、git など)で直接読み書きできることを重視しますか?** それとも、データファイルはツールに任せて、**書き込みの安全性と検索性を優先しますか?**

- **A. SQLite データベースファイル(1つの .db)** — クラッシュセーフな書き込みと索引付き検索。ただしファイルはバイナリで、閲覧・編集には SQLite ツールが必要
- **B. 単一 JSON ファイル** — 実装が最も単純で人間が読める。ただし全ノートを毎回丸ごと書き直すため、クラッシュ時の破損リスクは最大
- **C. ノートごとのプレーンテキスト/Markdown ファイル** — エディタ・grep・git で個別に自由に扱える。ただし横断検索は全ファイル走査になり、メタデータ管理は自前実装
